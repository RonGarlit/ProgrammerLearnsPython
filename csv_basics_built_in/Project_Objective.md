# 📄 CSV Basics with Python's Built-in `csv` Module

Below is a complete, runnable Python application designed to teach a beginner
**how to read and write CSV files** using only the Python **standard library** —
no third-party packages required. It's a small interactive "study session" that
walks through each concept with real working examples, heavy commenting, and
links to the official Python documentation for further reading.

---

## Code Analysis Summary

- **Purpose:** A single-file interactive teaching tool that demonstrates working
  with CSV (comma-separated values) data using the built-in `csv` module.
- **Concepts covered:** what a CSV file is, reading with `csv.DictReader`,
  writing with `csv.DictWriter`, filtering & writing results, `csv.reader` /
  `csv.writer`, automatic quoting of tricky data, and combining the concepts in
  a real mini task.
- **Style:** Heavily commented so each construct is explained *where it
  appears*; safe for beginners — the only files it creates are small CSV data
  files in the same folder (`employees.csv`, `managers.csv`, `numbers.csv`,
  `tricky.csv`).
- **Notable patterns:** Uses `read_csv_builtin()` / `write_csv_builtin()`
  helpers (the exact pattern from the classic "Example 1: Using Built-in `csv`
  Module"), a `main()` function as an entry point, a `menu`-driven loop, and a
  classic `if __name__ == "__main__"` guard.

## Design Principles

### 1. Built-in only, zero dependencies
Everything uses the Python standard library (`csv` and built-in functions). A
beginner can run this on any Python 3.6+ install with nothing to `pip install`.

### 2. The classic helper pattern
The two helper functions mirror the well-known introductory pattern:

```python
def read_csv_builtin(filename):
    data = []
    with open(filename, 'r') as file:
        reader = csv.DictReader(file)
        for row in reader:
            data.append(row)
    return data
```

and

```python
def write_csv_builtin(data, filename):
    fieldnames = data[0].keys()
    with open(filename, 'w', newline='') as file:
        writer = csv.DictWriter(file, fieldnames=fieldnames)
        writer.writeheader()
        writer.writerows(data)
```

These are real, reusable code — not just toy snippets.

### 3. One-concept-per-section
Like the `basics` tutorial, each section is its own function so a learner can
study it in isolation and re-run any part on demand.

### 4. Progression from easy → applied
- Sections 1–3 establish the fundamentals (raw text, read, write).
- Section 4 combines them (filter → write), which is the user's example.
- Sections 5–6 broaden the tools (list-style access, quoting gotchas).
- Section 7 ties everything together with a practical task.

### 5. Strings, not numbers
CSV files store text. The lessons deliberately show `int(emp['salary'])`
conversion so beginners learn that math on CSV data requires type conversion.
