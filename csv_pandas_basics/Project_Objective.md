# 🐼 Pandas Basics with Python

Below is a complete, runnable Python application designed to teach a beginner
**how to work with tabular data using pandas** — the de-facto standard library
for data analysis in Python. It's a small interactive "study session" that
walks through each concept with real working examples, heavy commenting, and
links to the official pandas documentation for further reading.

> This folder covers **pandas basics only**. Intermediate and advanced pandas
> (merging, pivoting, time series, vectorized operations, etc.) will be built
> out in later folders.

---

## Code Analysis Summary

- **Purpose:** A single-file interactive teaching tool that demonstrates
  working with CSV data using **pandas** and its `DataFrame` object.
- **Concepts covered:** what pandas is & how to install it, reading with
  `pd.read_csv`, exploring with `head`/`info`/`describe`/`shape`, selecting
  columns & rows with `loc`/`iloc`, boolean filtering, adding & modifying
  columns, grouping & aggregating with `groupby`, writing with `to_csv`, and
  combining the concepts in a real mini task.
- **Style:** Heavily commented so each construct is explained _where it
  appears_; safe for beginners — the only files it creates are small CSV data
  files in the same folder (`high_sales.csv`, `monthly_summary.csv`).
- **Notable patterns:** Uses `read_csv_pandas()` / `write_csv_pandas()`
  helpers (the exact pattern from the classic "Example: Using pandas" intro),
  a `main()` function as an entry point, a `menu`-driven loop, and a classic
  `if __name__ == "__main__"` guard.

## Design Principles

### 1. Third-party, but one install

Unlike the built-in `csv` module, pandas must be installed once:

```powershell
pip install pandas
```

After that, everything in this lesson uses pandas only — no other packages.

### 2. The classic helper pattern

The two helper functions mirror the well-known introductory pattern:

```python
def read_csv_pandas(filename):
    return pd.read_csv(filename)
```

and

```python
def write_csv_pandas(df, filename):
    df.to_csv(filename, index=False)
```

These are real, reusable code — not just toy snippets.

### 3. One-concept-per-section

Like the `csv_basics_built_in` tutorial, each section is its own function so a
learner can study it in isolation and re-run any part on demand.

### 4. Progression from easy → applied

- Sections 1–3 establish the fundamentals (what pandas is, read, explore).
- Sections 4–6 broaden the tools (select, filter, modify).
- Section 7 introduces the powerful `groupby` aggregation.
- Section 8 shows writing results back to CSV.
- Section 9 ties everything together with a practical task.

### 5. Numbers, not strings

Unlike the built-in `csv` module (which returns strings), pandas **infers
types** automatically — `amount` and `quantity` come in as integers, so math
works immediately without manual `int()` conversion. This is a key selling
point of pandas and is highlighted throughout.
