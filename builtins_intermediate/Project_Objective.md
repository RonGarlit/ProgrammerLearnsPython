# 🔧 Python Intermediate Built-ins

Below is a complete, runnable Python application designed to take a beginner
**from Python fundamentals to the practical, everyday standard library**.
Building on the `builtins_basics` folder, this interactive "study session" adds
the built-in modules and syntax that make Python truly productive — reading
files, working with JSON, handling dates and times, using specialized
containers, writing expressive comprehensions and generators, and building
flexible functions. All of it uses only the **Python standard library** — no
third-party packages.

> This folder covers **intermediate built-ins**. More advanced Python topics
> (object-oriented programming, decorators, context managers, type hints, and
> deeper standard-library tools) are in the `builtins_advanced` folder.

---

## Code Analysis Summary

- **Purpose:** A single-file interactive teaching tool that demonstrates the
  practical Python standard library modules a beginner meets right after the
  core language.
- **Concepts covered:** `pathlib` file I/O, the `json` module, the `datetime`
  module, `collections` (`Counter`, `defaultdict`, `namedtuple`, `deque`),
  list/dict/set comprehensions, generators, `*args`/`**kwargs`, and
  `lambda` + `map`/`filter`.
- **Style:** Heavily commented so each construct is explained *where it
  appears*; safe for learners continuing from `builtins_basics` — the only
  files it creates are small text/JSON outputs in the same folder
  (`copied_notes.txt`, `log_summary.json`).
- **Notable patterns:** Uses a `main()` menu loop, a classic
  `if __name__ == "__main__"` guard, and a `data_path()` helper so paths
  resolve relative to the script (works from any folder). Sample data lives in
  `notes.txt`, `settings.json`, and `log.json`.

## Design Principles

### 1. Assumes Python fundamentals are done
This folder advances past variables, loops, and functions. If you don't
recognize those yet, complete `builtins_basics` first. The lesson reuses the
familiar `main()` menu and `if __name__` structure so the learner sees
continuity.

### 2. Built-in only, zero dependencies
Everything uses the Python **standard library**. A learner can run this on any
Python 3.6+ install with nothing to `pip install` — exactly like
`builtins_basics`.

### 3. Real, usable modules
Every section maps to a module a developer actually uses daily: `pathlib` for
files, `json` for data exchange, `datetime` for time, `collections` for
specialized containers. This is the natural "next step" after learning the
core language.

### 4. One-concept-per-section
Like every other folder in this repo, each section is its own function so a
learner can study it in isolation and re-run any part on demand.

### 5. Progression from easy → applied
- Sections 1–4 cover the big everyday modules (files, json, datetime, collections).
- Sections 5–8 add expressive syntax (comprehensions, generators, flexible args, lambdas).
- Section 9 ties everything together with a realistic JSON-processing task.

### 6. Dark-mode-friendly, modern idioms
Uses `pathlib.Path` (the modern replacement for `os.path`), f-strings, and
`with` for safe file/JSON handling — teaching the professional, up-to-date way
to write Python.
